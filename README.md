## Что изменено

- Отдельные сгенерированные баннеры для ПК и телефона. Логотип справа внизу широкого баннера, фирменный знак в футере.
- Новый каталог: вертикальные карточки, крупные фотографии, видимые размеры, удобные фильтры и аккуратная страница всех категорий.
- Новый конструктор: категории выбора, параметры размеров, закреплённая цена, выбор и замена вещей. Исправлено зависание при повторном открытии выбора.
- Новая страница входа с фотографией, ясной формой и мобильной компоновкой; сохранены существующие способы входа и подтверждения.
- Контрастный хедер светлой темы на всех страницах витрины и входе: читаемые надписи, иконки и логотип.
- Проверки отсутствия наложений карточек и выхода кнопок за границы на ширинах 320–1440 px в обеих темах.
- Новая главная: крупный первый экран, категории, конструктор комплекта, консультация по размеру, статьи и FAQ. Убраны повторяющиеся блоки категорий и комплектов.
- Единая палитра: графит, олива, тёплый оранжевый. Тёмная тема по умолчанию; выбор светлой темы сохраняется.
- Обновлены мобильная версия, карточки каталога, контраст, состояния фокуса и доступность полей оформления заказа.
- Исправлена загрузка товара по прямой ссылке без готовых данных страницы: адрес больше не заменяется демонстрационным товаром `p1`.
- Исправлены ссылки на одежду, обувь и медицину в футере.
- Текст об оплате в карточке учитывает включённые способы. Блок поддержки армии в оформлении отображается при включённой программе в данных витрины.
- Ключи из `api/mono-private.php` и `api/np-private.php` заменены чтением из переменных окружения. Самих ключей в обновлённом архиве нет.

## Посмотреть дизайн локально

Нужны Node.js 22+ и npm. Из папки проекта:

```sh
npm ci
npm run preview
```

Сервер слушает порт 4173 только на `127.0.0.1`. При занятом порте: `PORT=4174 npm run preview`.

Это **демонстрационный режим** с явно обозначенными примерными товарами, ценами и остатками. Он показывает главную, каталог, поиск, карточки, избранное, корзину и оформление. Создание заказов, платежи, авторизация и отправка сообщений отключены. Страница `/auth/` также доступна для проверки дизайна при установленном PHP (или переменной `PHP_PATH`). Вход и отправка писем в просмотре выключены. Демо-данные находятся только в `dev/fixtures.mjs`; PHP-магазин их не использует.

## Проверки

```sh
# Если Chromium установлен в системе:
CHROMIUM_PATH=/usr/bin/chromium npm test

# Иначе установить браузер для Playwright:
npx playwright install chromium
npm test
```

Все 22 браузерные проверки прошли. Тесты сами запускают изолированный сервер на свободном порте. Они проверяют навигацию, прямые ссылки товаров, поиск, сохранение размера и корзины, расчёт суммы, ограничение количества по остатку, доступность способов оплаты, избранное с клавиатуры, мобильное меню, размеры экранов, тему, ошибки каталога и запрет платежей в демо-режиме.

На подготовленном окружении также проверен синтаксис всех 73 PHP-файлов. Это не заменяет проверку PHP-магазина с реальной MySQL-базой и настройками сервисов.

## Установка на существующий хостинг

Смотрите [инструкцию по установке](docs/DEPLOYMENT.md). **Не заменяйте существующие приватные настройки, базу и папку фотографий всем содержимым архива.** Начните с копии магазина на тестовом поддомене. Производственная версия по-прежнему требует PHP, MySQL и Apache с правилами `.htaccess`.
