# Выбор спорядження и скорость

На живом сайте запросы `slot=body` и `slot=head` возвращали 503. Общий запрос каталога с наличием в одном замере не завершился за 40 секунд. Конкретное серверное исключение без журнала хостинга не установлено.

Исправления:

- Отдельный общий кеш набора товаров для каждого из 8 слотов. Поиск, размер, цвет, наличие и страницы фильтруют этот набор, не повторяя тяжёлые REGEXP запросы к вариантам.
- Предзагрузка рекомендаций, немедленное отображение доступных карточек, повторное использование ответов на 30 секунд. Общий каталог не загружается при открытии конструктора.
- Индикатор загрузки, явная ошибка с повтором и отдельное настоящее пустое состояние. Ответ от предыдущего слота/поиска не может заменить новый.
- Предварительный прогрев слотов и входных страниц через существующий cache worker.
- Контекст обязательного размера вычисляется один раз вместо вложенных SQL CASE в каждой проверке варианта.
- Яркая оранжевая кнопка выбора, центрирование и высота от 48 px, выделенная инструкция в обеих темах.
- Датированные статические файлы получают отдельные правила кеширования; PHP и приватные конфигурации не кешируются этими правилами. Сжатие Brotli на хостинге уже работает. Применение Apache Cache-Control необходимо проверить после установки: nginx может обслуживать файлы самостоятельно.

На локальной копии 2457 товаров / 7336 вариантов: холодный набор слота 22–127 мс, тёплый поиск и фильтры 8–22 мс. До изменений slot-запросы занимали 0,56–0,80 секунды, фильтр цвета до 2,42 секунды. Это время PHP/API на локальной машине, не обещание времени загрузки на хостинге или через мобильную сеть.

Проверены: все слоты, совместные фильтры одного варианта, 24+7 товаров без повторов между страницами, реальные размеры, запрет неподтверждённых размеров, загрузка/503/повтор, кеш при повторном открытии, мобильные размеры и обе темы.

После установки: `php dev/check-kit-catalog.php` проверяет все 8 слотов на живой базе и выводит время каждого. Существующий cron продолжает прогрев; настройку cron и эффективность заголовков нужно подтвердить на хостинге.
