# Компактный каталог и категории

Подготовлена новая раскладка по предоставленному образцу. Исходники обновлены; установка на хостинге ещё не выполнена.

- В каталоге категории показаны двумя компактными рядами с переключением страниц: 10 на широком экране, 8/6 на среднем и 4 на телефоне. Ссылки ведут в соответствующие разделы. «Усі категорії» открывает полный каталог разделов.
- Страница всех категорий использует карточки одинаковой высоты. Длинные ветки, включая «Одяг та форма», открываются в отдельном нативном диалоге с прокруткой, закрытием по Escape и возвратом фокуса. Поиск находит также названия вложенных категорий.
- Фото категории выбирается по точному названию из `assets/category-directory.2026100604.js`. Убрана подстановка картинки аксессуаров/перчаток в произвольные разделы. Можно задать полный словарь через `window.RUBIZH_DIRECTORY_BANNERS`; изображения должны соответствовать конкретной категории.
- На широком экране сетка товаров содержит две колонки горизонтальных карточек с фотографией слева и данными справа. На планшете и телефоне карточки вертикальные. Изображения товаров отображаются целиком; цены, размеры, наличие и ссылки берутся из прежних данных каталога.
- Сортировка на компьютере использует выпадающий список. Фильтры, избранное, корзина, мобильная сортировка, конструктор и тема сохранены.

## Баннеры: незавершённый этап

Для этого обновления пользователь предоставил архив из 21 баннера. Инструмент скачивания отклонил архив из-за лимита 32 МиБ. Альтернативная папка Google Drive пока перенаправляет на вход Google, поэтому оригиналы недоступны. До получения файлов для шести известных разделов используются их прежние корректные изображения; у остальных нейтральная номерная плашка. Это временное состояние, а не готовая привязка всех 21 баннеров. Их нужно скачать после открытия доступа, просмотреть, сопоставить с разделами и заменить словарь изображений перед окончательной установкой.
