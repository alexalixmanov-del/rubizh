# CRM РУБІЖ — формулы аналитики (этап 4)

Код: `staff/lists.php` (`crmPeriod4`, `crmMoneyFacts`, `crmGrossProfit`, `crmDashboard4`, `crmAnalytics`). Тесты формул: `tests/crm-stage4-api.test.mjs`, `tests/crm-stage4-status.test.mjs`. Доступ: «Аналітика» и валовая прибыль — OWNER, ACCOUNTANT; «Робота менеджерів» — только OWNER (M-13).

## Период

- Календарь — **Europe/Kyiv**; границы `[from, to)` переводятся в UTC (хранение — UTC, A8). Переход на летнее/зимнее время учитывается библиотекой дат.
- Сьогодні; 7 днів (сегодня и 6 предыдущих дней); 30 днів; Цей місяць (с 1-го числа по сегодня); Минулий місяць; Власний період (≤ 370 дней).
- Период сравнения: такой же длины непосредственно перед выбранным; для «Цей місяць» — тот же отрезок прошлого месяца (с 1-го по то же число), для «Минулий місяць» — позапрошлый месяц.

## Деньги (целые копейки, валюта 980)

| Показатель | Формула |
|---|---|
| Виручка | Σ сумм счетов MonoPay, по которым есть **подписанное** событие `success` с датой первого успеха в периоде + Σ принятых оплат по счёту ФОП (D-51, дата из выписки) |
| Оплачених замовлень | число различных заказов в выручке |
| Середній чек | Виручка ÷ Оплачених замовлень (целочисленное деление, копейки) |
| Повернення | Σ успешных операций возврата (ledger `rubizh_refund_operations`, `status='success'`) с датой в периоде |
| Чиста виручка | Виручка − Повернення |
| Валовий прибуток | Виручка − Повернення − Σ(кількість × собівартість SKU) по оплаченим в периоде заказам. Собівартість = выплата поставщику из PIM (`rubizh_crm_sku_costs`). **Если хотя бы для одного SKU нет собівартості — показатель не считается** (`available:false`, «Немає даних собівартості від PIM», OD-4.1) |
| Замовлення (KPI) | число созданных в периоде заказов (любых статусов) |
| Очікують обробки | заказы «очікує підтвердження» + «оплачені, без відправлення» (текущее состояние, не период) |

Наложенного платежа нет (A5): ни в одной формуле нет и не может быть «післяплата».

## Разрезы

- По менеджерам — назначенный менеджер заказа (`rubizh_order_assignments`), «Не призначено» отдельно; сумма заказа целиком.
- По поставщикам — сумма строк заказа (`line_amount`) с кодом поставщика строки; «Без постачальника» — строки без кода (LOG-05).
- По категориям — `products.category_path` строки; «Без категорії».
- По каналам — `contact_json.channel` (`phone`, `instagram`, `tiktok`, `other`), иначе `web`.
- Нові / повторні покупці: покупатель = аккаунт, иначе нормализованный телефон заказа, иначе email. Повторный — если у него есть оплаченный заказ, созданный до начала периода.

## Огляд

- График: по дням (Киев) — заказы и выручка; линия сравнения — выручка периода сравнения, выровненная по номеру дня.
- «Заказы по статусам» — по проекции [02-CRM_STATE_MAP](02-CRM_STATE_MAP.md) для заказов, созданных в периоде.
- «Популярні товари» — топ-5 SKU по количеству в неотменённых заказах периода.
- «Робота менеджерів» (OWNER) — назначено / підтверджено / завершено; без рейтингов и оценок.
