## Отложено (DEFERRED)

- Значок героя на ширинах < 1440 скрыт (места рядом с товаром нет) — вернуть иначе только по дизайну.
- Переносы по слогам для украинского в Chromium не поддерживаются — используется масштаб шрифта.
- Неизвестные камуфляжи (Камуфляж, Очерет, Листя, …) — словарь владельца в PIM.
- Решения владельца: сетка размеров M-WIN, режим наличия Тактикал Белт, профили поставщиков → AUTOPRICES (PREVIEW).
